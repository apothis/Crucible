# Loosh Woggins: album styles, channel and release plan

Status: plan, 2026-09-22. Persona, album and Suno house rules are in the
conversation brief; bio and press-kit text live in .mvwork/loosh_woggins_bio.txt,
cover in .mvwork/loosh_woggins_cover.webp, one-sheet in .mvwork/loosh_woggins_presskit.webp.

Canon decision (2026-09-22): the WHOLE album is Hillbilly Country Dubstep.
Every track carries at least one [Build-Up] / [Drop] pair; the country subgenre
underneath varies per song so the ten tracks do not blur together.

## 1. Style fields (Suno v6, one per track)

House rules applied: one comma list, 30-45 words, no periods, tempo + key +
subgenre first, 2-3 instruments with adjectives, one male vocal descriptor,
production words, journey phrases last. Negatives go in Exclude Styles.

Shared Exclude Styles (paste for every track, trim per song if needed):
female vocals, pop, trance, house, techno, clean radio country, autotune, choir, orchestra

Sliders: Weirdness 50-60, Style Influence 70, Variety Normal. v6 for the
songs that must land (1, 5, 7, 9), one v6-wild roll each on 2, 4, 8, 10. Track 3 is done.

## 6. Image generation: where the stills come from

What made the Copilot images: Copilot's image generator is built on OpenAI's
GPT image models (gpt-image family) and, since late 2025, Microsoft also routes
some requests to its own MAI-Image-1. Which of the two produced these exact
images cannot be told from the output; the clean rendered text on the one-sheet
is characteristic of the GPT image family. Treat this as informed guess, not fact.

Options, cheapest workable first:
1. ChatGPT Plus, 20 USD/month. Same model family as Copilot's default, generous
   rate-limited image generation, and the cover can be uploaded as a reference
   image in every prompt for identity consistency. Recommended as the main tool.
   Test before committing: generate the banner and three press stills with the
   cover attached, compare against the Copilot output. If identity holds, stay.
2. Google AI Pro, 20 USD/month, for Gemini's image model (Nano Banana Pro).
   Strong at text rendering and multi-image reference consistency. Worth one
   test on the same brief if Plus disappoints; not needed if Plus holds.
3. Yapper per-image GPT access: keep for one-off emergencies only; the per-image
   price is what makes Plus the better deal at the volume below.
4. Local on the box, free: Krea2 Identity Edit (reference re-staging) with the
   cover as the identity source, or Z-Image Turbo for props and backgrounds.
   Quality has not been compared against the Copilot stills for this character;
   run one A/B before relying on it. Useful for bulk variants even if Plus does
   the hero shots.

Volume estimate for the whole album: banner + profile + watermark (5-8 attempts),
one thumbnail per song (10-20), six to ten story stills per song (60-100 plus
rejects). Roughly 150-250 generations, well inside a Plus month.

Prompt skeleton that matches the existing look (reuse verbatim, swap the scene):

## 7. Visuals per song without generated video

Chosen direction: photo-story lyric videos. Each song gets 6-10 stills that tell
the lyric as a sequence (Gym Membership: Fitbit on the pillow, protein tub where
the biscuits were, Blake the trainer, rotisserie chicken in the parking lot),
cut to the song's sections, with slow Ken Burns moves and woodtype lyric
captions. No AI video at all; motion comes from pans, zooms, cuts and a reactive
element on the drops.

Build path (all ffmpeg, extends the existing 1 fps recipe):
- Stills at 2048 wide or better so a 1.15x zoom over 20-30 s stays sharp.
- One clip per still via zoompan, 25 fps, 1920x1080, sepia paper frame overlay.
- Lyric captions via drawtext or a pre-rendered PNG per line, timed from a
  simple cue file (start, end, text, style). Chorus lines bigger, drops get the
  neon accent and a shake (small random x/y offset for the drop bars).
- Waveform strip along the bottom on the drops only (showwaves), styled ivory
  like the app's modern look, so the wobble is visible.
- Concat with 12-frame crossfades, mux the wav at 320k AAC, faststart.
- Same still set re-cropped to 1080x1920 for a 45-60 s Short around the first
  drop.

Alternative if the app should own it: add an opt-in "saloon" look to the
existing YouTube card-video pipeline (paper backdrop, Rye lettering, waveform
on the drops), default remains modern. That gives every future Loosh track a
one-click card video without touching the photo-story recipe.

Full-album video: the ten photo-story videos concatenated with chapter markers
in the description; the cover on black as the idle frame between tracks.
